## Висновок
Під час виконання практичної роботи було опановано роботу з однозв’язним списком forward_list у мові програмування C++. На практиці реалізовано основні операції: створення та ініціалізацію списку, перегляд і пошук елементів за допомогою ітераторів, додавання елементів на початок (push_front), видалення з початку (pop_front), а також вставку нового елемента після знайденого за допомогою методу insert_after. Робота продемонструвала переваги та особливості односпрямованого доступу до даних у структурі forward_list.
